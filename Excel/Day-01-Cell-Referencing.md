# Day 01 — Excel Cell Referencing

**Date:** 18 October 2026  
**Topic:** Relative, Absolute, and Mixed Cell Referencing

## 1. What I Learned

### Relative Reference
Example: `=B2*C2`

When copied to another row, the cell references adjust automatically.

### Absolute Reference
Example: `=$B$2*C2`

The reference to cell B2 remains fixed when the formula is copied.

### Mixed Reference
Examples:
- `$B2` — column B remains fixed.
- `B$2` — row 2 remains fixed.

## 2. Practice Tasks

1. Calculate revenue using Units Sold × Price per Unit.
2. Copy the formula down and observe how references change.
3. Use an absolute reference to apply a fixed discount rate.
4. Practise mixed references with a small multiplication table.

## 3. Key Takeaway

Cell referencing helps create accurate, reusable formulas and is an important foundation for spreadsheet analysis.
